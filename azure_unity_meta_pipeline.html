Step-by-Step: Making a Change End-to-End

1
Make the change Unity Editor
Open Unity Editor on your local machine and edit the project in D:\GitHub\knauf\hephaestus. Save with Ctrl+S when done.
2
Commit in GitHub Desktop GitHub Desktop
Open GitHub Desktop — your changed files appear in the left panel. Write a commit message and click Commit to main.
3
Push to Makeway GitHub GitHub Desktop
Click Push origin in GitHub Desktop. Backs up your work on Makeway's internal repo. Not part of the client pipeline.
4
Push to Azure DevOps Windows PowerShell
Open PowerShell and run: git push azure main. Verify the commit appears in the Azure DevOps browser.
5
Merge to release branch Windows PowerShell
git checkout release   git merge main   git push azure release
Repeat on release-vpt for VPT builds.
6
Trigger Unity Cloud Build Unity Cloud Dashboard (browser)
Go to Unity Cloud dashboard in your browser. Select the correct build config (e.g. KTA-Production). Click Build → Clean Build.
7
Wait for build to complete Unity Cloud Dashboard (browser)
KTA build: ~2 hours  ·  VPT build: ~2.5 hours. Monitor progress in the Unity Cloud dashboard. Build runs on Unity's cloud servers.

If changes affect both KTA and VPT, trigger both build configs at the same time — they run in parallel, so total wait is ~2.5 hours max, not 4.5. A Clean Build reprocesses everything from scratch. An incremental build only reprocesses what changed and can be significantly faster.
8
Download the APK Unity Cloud Dashboard (browser)
In Unity Cloud, find the completed build. Click the three-dot menu and select Download .APK. Save to your local machine.
9
Upload to Meta Quest Developer Hub Meta Quest Developer Hub (desktop app)
Open Meta Quest Developer Hub. Go to App Distribution tab. Select your app → Upload to Business channel.
10
Wait for Meta to process Meta Quest Developer Hub (desktop app)
Meta processes the APK upload. This takes approximately 20 minutes. Status is visible in the Developer Hub dashboard.
11
Distributed via Meta For Work
Update is pushed through Knauf's Quest for Business org to the correct device group (KTA or VPT). No manual action needed on headsets.
12
Headsets updated ✓
All enrolled headsets receive the update automatically on next app launch. No manual action needed on the headsets.
